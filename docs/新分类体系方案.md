# 日本陶艺知识库分类体系重构方案

## 一、当前问题总结

### 1. 格式不统一
- ❌ `"六古窯（Six Ancient Kilns）/ 历史发展"` - 中英文混合
- ❌ `"technique"` - 纯英文
- ❌ `"技法·様式（Techniques & Styles）/ 成型技法"` - 中日英混合

### 2. 层级混乱
- 同一分类同时存在父级和子级条目
- 父子关系不清晰（如"六古窯"和"六古窯/历史发展"）

### 3. 日语未翻译
- 侧边栏保留了大量日语原文（labelJa）
- 应全部翻译为中文

### 4. 分类覆盖不完整
- 技法分类仅展开了成型技法
- 器物分类未充分展开
- 缺少样式、时代等维度

---

## 二、新分类体系设计

### 核心原则
1. **纯中文命名** - 删除所有英文和日文括号
2. **清晰层级** - 最多两级（一级分类/二级分类）
3. **互斥完整** - 同一层级分类互不重叠、完整覆盖
4. **语义明确** - 每个分类名称直观易懂

### 一级分类（7大类）

```
1. 产地窑系 (127条)
   ├─ 六古窑 (65条)
   └─ 现代名窑 (62条)

2. 制作技法 (56条)
   ├─ 成型技法
   ├─ 装饰技法
   ├─ 釉药技法
   └─ 烧成技法

3. 器物用途 (30条)
   ├─ 茶道具
   ├─ 酒器
   ├─ 日用器
   └─ 储藏器

4. 艺术样式 (新增)
   ├─ 志野
   ├─ 织部
   ├─ 黄濑户
   └─ 乐烧

5. 历史文化 (26条)
   ├─ 美学思想
   ├─ 文化史
   ├─ 茶道文化
   └─ 民艺运动

6. 基础知识 (3条)
   ├─ 术语解释
   ├─ 鉴赏体系
   └─ 文化认定

7. 陶艺作家 (60位)
```

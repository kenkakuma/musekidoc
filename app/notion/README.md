# Notion风格布局 - 访问指南

## 🎯 访问地址

已部署在独立路径，不影响现有布局：

- **Notion首页**: http://localhost:3000/notion
- **陶器列表**: http://localhost:3000/notion/pottery
- **传统布局**: http://localhost:3000/

## 🎨 布局特色

### 和纸数字图书馆美学

**视觉设计**
- 📜 和纸纹理背景（SVG噪声滤镜）
- 🖋️ 墨色层次渐变（浓墨→淡墨）
- 🏺 陶土与青瓷色调
- ✨ 手工感边框装饰
- 🧘 禅意留白空间

**功能特性**
- 📂 可折叠侧边栏导航树
- 🔍 全局搜索框
- 🗂️ 三种数据库视图（表格/画廊/列表）
- 🥖 面包屑导航
- 🎯 当前页墨迹高亮

## 📱 响应式支持

- ✅ 桌面端：完整侧边栏 + 宽内容区
- ✅ 平板端：可折叠侧边栏
- ✅ 移动端：自动调整网格列数

## 🔄 布局切换

页面右下角有**布局切换器**，可以：
- 在传统布局和Notion布局间切换
- 查看当前使用的布局类型
- 快速体验不同风格

## 🛠️ 技术实现

- **框架**: Next.js 14 App Router
- **样式**: Tailwind CSS + Custom CSS
- **字体**: Noto Serif JP/SC (明朝体)
- **动画**: CSS keyframes + 交错延迟
- **图标**: Lucide React

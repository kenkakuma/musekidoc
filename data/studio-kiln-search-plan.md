# 80位作家窑场/工作室信息搜索计划

**创建日期**: 2026-03-03
**目标**: 完善所有80位作家的窑场、工作室、地点信息

## 目标信息

### 核心数据
1. **窑场名称**（窯名）：如"休雪白窯"、"龍太窯"等
2. **工作室名称**（工房/スタジオ/アトリエ）：如"studio knot"、"bonoho"等
3. **具体地点**：
   - 都道府県
   - 市区町村
   - 详细地址（如有）
4. **窑炉类型**：
   - 薪窯（wood-fired kiln/nobori-gama）
   - 電気窯（electric kiln）
   - ガス窯（gas kiln）
   - 穴窯（anagama）
   - その他

## 搜索策略

### 关键词组合
1. **日文搜索**：
   - `[作家名] 窯 工房 スタジオ`
   - `[作家名] 窯元 所在地`
   - `[作家名] アトリエ 場所`
   - `[作家名] 工房 住所`

2. **英文搜索**：
   - `[Artist Name] studio kiln location`
   - `[Artist Name] workshop Japan address`
   - `[Artist Name] pottery studio where`

3. **官网直接查询**：
   - 作家官方网站
   - Instagram简介
   - 画廊代理页面
